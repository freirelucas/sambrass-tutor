# CLAUDE.md

Orientações para o Claude Code neste repositório.

## Fluxo de Git

- **Trabalhe direto no `main`.** Comite e dê push do trabalho concluído
  diretamente em `main` — não criar branch de feature + PR como padrão.
  (Instrução explícita do dono do repo em 2026-06-14: "pode passar a
  empurrar tudo pro main sempre".)
- Faça push assim que o trabalho estiver concluído e verificado.
- Se em algum momento o usuário pedir um PR explicitamente, aí sim use branch + PR.
