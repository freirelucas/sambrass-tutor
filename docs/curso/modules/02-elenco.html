O personagem mais estranho: o service worker

Ele se senta entre o app e a internet e decide, pedido a pedido, se vai à rede ou abre a cópia guardada.

“Eu respondo por este pedido” — o service worker intercepta.

Tenta a internet primeiro. Esta é a estratégia network-first.

Deu certo? Guarda uma cópia para a próxima — mas devolve a versão fresca agora.

Entrega a resposta da rede.

Deu errado (sem sinal)? Aí sim, abre a cópia guardada.

💡
A escolha que importa

Código e dados usam network-first: você sempre vê a versão nova. Mas os sons do trompete e as gravações da banda usam cache-first — são grandes e nunca mudam. Saber nomear essas duas estratégias é exatamente o tipo de vocabulário que faz uma IA acertar de primeira.

Teste rápido

Você quer que cada peça ganhe uma nota de dificuldade calculada a partir das notas. Onde esse cálculo deve morar?

Você publica uma correção às 10h. Um usuário com internet abre o app às 10h05. O que ele vê?
