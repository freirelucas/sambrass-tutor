Quando quebra

Cada sintoma deste app tem um endereço provável. Saber esse mapa é a diferença entre consertar em cinco minutos e ficar preso num loop com a IA.

Diagnóstico por sintoma

Um mecânico não abre o carro inteiro: ele ouve o barulho e já sabe onde olhar. Aqui funciona igual.

🫥
Tela abre vazia, sem erro

Um JSON sumiu ou mudou de nome. Rode python3 tools/check_contrato.py — ele compara os dois lados.

🎨
Botão aparece “cru”, sem estilo

A página usa uma classe que a folha dela não define. python3 tools/check_css.py.

🔇
Mudei o código e nada mudou no celular

Service worker servindo a versão guardada. Suba o número do cache em sw.js.

🎵
A nota está errada na partitura

Não é bug de código: é dado. O problema nasceu na transcrição, em content/.

📵
Funciona online, falha offline

A página não está no SHELL do service worker — só entra no cache depois da primeira visita.

A rede que segura a queda

O projeto tem três guardas diferentes, e cada um pega uma família de erro:

🧾

Guards estáticos

Leem o código sem rodar nada. Pegam contrato de dados e classe sem estilo. Rápidos, rodam no CI.

🌐

22 testes de navegador

Abrem o app de verdade num Chromium e clicam. Pegam o que só aparece na tela.

🎼

Validadores de dados

Conferem compassos, alturas e referências das 126 peças. Pegam erro musical, não de código.

💡
A regra de ouro para usar IA aqui

Um teste que só passa não prova nada. Peça sempre: “quebre de propósito e me mostre o teste ficando vermelho”. Nesta base, essa exigência já revelou um teste que usava OR no seletor e, por isso, passava mesmo com metade da tela morta.

O que dizer para a IA — e o que não dizer

✅

Instruções que funcionam

“Isto é um site estático no GitHub Pages — não proponha backend nem banco.”

✅

Onde fazer a conta

“O resultado é igual para todo mundo: calcule no pipeline Python, não no app.”

✅

A premissa do front

“O app é vanilla, sem build e sem framework. Não adicione dependências.”

❌

“Adicione login de usuário”

Não há servidor para autenticar ninguém. O progresso vive só no aparelho.

❌

“Só renomeia esse JSON”

Renomear um lado só falha em silêncio. Os dois lados, sempre — e rode o guard.

❌

“Os testes passaram, pode subir”

Passar não é prova. Peça o teste falhando antes de acreditar nele.

Teste final
